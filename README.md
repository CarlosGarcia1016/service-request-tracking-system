# service-request-tracking-system
Sistema de seguimiento para solicitudes de servicio interno en GE HealthCare.
# Sistema de Seguimiento de Solicitudes Internas

Este proyecto consiste en el desarrollo de una aplicación web para registrar,
consultar y dar seguimiento a solicitudes internas dentro del área de
Engineering Infrastructure & Digital de GE HealthCare.

## Problema identificado

Actualmente parte de la información de las solicitudes se encuentra distribuida
entre correos electrónicos y archivos de Excel, lo que dificulta conocer su
estado, responsable y tiempo de atención.

## Alcance de la versión Beta

- Inicio de sesión.
- Registro de solicitudes.
- Consulta de solicitudes.
- Asignación de responsables.
- Cambio de estado.
- Historial básico de cambios.
- Prueba automatizada con JUnit.

## General Availability

- Dashboard básico.

- Documentación.
